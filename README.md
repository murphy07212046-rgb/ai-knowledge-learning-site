# AI 知识地图

面向公开网络的 AI 学习站。它以“用户提问 → AI 回答”的完整链路组织 7 个模块，并提供 30 天 AI 产品经理训练路径、可下钻的知识卡片、真实业务案例演练（含各环节风险提示）与每日公开资讯更新。

## 本地查看

直接双击打开 [public/index.html](public/index.html) 即可查看完整页面，无需启动本地服务。页面的“30 天训练”先给出每周学习目标、实战案例和必须完成的产出；首屏的“真实业务案例 · HR 数据查询助手”会直接展示案例摘要，点击“查看完整案例演练”可展开完整拆解。每个案例环节均展示可能问题、用户可见症状和优先检查项。

如需以静态服务方式预览：

```bash
npm run start
```

## 内容更新

知识数据同时提供两个版本：

- `public/data/knowledge.json`：数据源和维护版本。
- `public/data/knowledge.js`：供浏览器直接打开 HTML 时加载的版本。

手动编辑 JSON 后运行：

```bash
npm run sync-data
```

每日刷新公开来源并生成摘要、归入对应知识模块：

```bash
npm run refresh
```

GitHub Actions 会在每天 09:15（北京时间）自动运行，也可以从 Actions 页面手动运行 `Refresh public AI knowledge`。如配置 AI 摘要能力，在仓库 Secrets 中设置：

- `AI_API_KEY`
- `AI_API_BASE_URL`（可选）
- `AI_MODEL`（可选）

设置密钥后，任务会按内容语义归入现有模块和具体知识点，并保存“为什么归到这里”的学习关联说明；页面会在对应模块和全局更新区同时展示。若遇到高置信度、长期有效且无法归入现有框架的 AI 能力，会自动新增一个学习模块及入门知识点，之后的每日更新也会继续归入该模块。单次产品公告、短期热点和低置信度主题不会扩展框架。未设置密钥时，任务仍会使用公开来源的原始摘要和关键词归类更新内容。密钥不得写入代码、数据文件或网页。

## 部署到 Cloudflare Pages

1. 将该项目推送到 GitHub 仓库。
2. 在 Cloudflare Pages 创建项目并连接该仓库。
3. 若仓库根目录就是本项目：构建命令留空，输出目录填写 `public`。
4. 若项目位于仓库子目录：将该目录设为 Root directory，输出目录仍填写 `public`。
5. 选择生产分支并部署。之后 GitHub Actions 提交新的知识数据，Cloudflare Pages 会自动重新发布。

## 公网内容边界

站点仅采集公开来源。真实业务案例只保留可学习的业务链路，并进行脱敏：不公开内部组织名称、人员信息、精确人数、数据表字段、内部接口或时间戳。
